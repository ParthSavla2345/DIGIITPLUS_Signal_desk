# SignalDesk — Incident Lifecycle

## Sequence Diagram

```mermaid
sequenceDiagram
    actor User
    participant FE as React Frontend
    participant BE as Express Backend
    participant DB as Supabase PostgreSQL
    participant Gemini as Google Gemini API
    actor Eng as Human Engineer

    %% === INCIDENT CREATION ===
    User->>FE: Submit incident title + description
    FE->>BE: POST /api/incidents
    BE->>BE: Zod validation
    BE->>DB: INSERT into incidents (status=open, analysis_status=pending)
    DB-->>BE: incident.id returned
    BE-->>FE: 201 { incident } — IMMEDIATE RESPONSE
    FE->>User: Navigate to incident detail page
    Note over FE: Shows "🤖 AI is analyzing..."
    FE->>FE: Polls every 5s for analysis completion

    %% === AI PIPELINE (background) ===
    BE->>BE: Background: runAnalysisPipeline()
    BE->>DB: UPDATE analysis_status=processing

    BE->>Gemini: Triage prompt (title + description)
    alt Triage Success
        Gemini-->>BE: Structured JSON {category, priority, severity, team...}
        BE->>BE: Zod validate response
        BE->>DB: UPDATE incidents (category, priority, severity, team, sentiment)
        BE->>DB: INSERT incident_activity "🤖 AI triage completed"
    else Triage Failure
        Gemini--xBE: Error / timeout / rate limit
        BE->>DB: UPDATE analysis_status=failed
        BE->>DB: INSERT incident_activity "⚠️ AI analysis failed"
        Note over BE: Incident still exists and is accessible
    end

    %% === EMBEDDING + RAG ===
    BE->>Gemini: Generate embedding (RETRIEVAL_QUERY, 768-dim)
    Gemini-->>BE: float[768]
    BE->>DB: RPC match_resolved_incidents(embedding, threshold=0.50, limit=5)
    DB-->>BE: Similar resolved incidents + similarity scores
    BE->>DB: RPC match_knowledge_articles(embedding, threshold=0.50, limit=3)
    DB-->>BE: Relevant knowledge articles + similarity scores
    BE->>DB: INSERT incident_activity "🔎 Similar incidents retrieved"
    BE->>DB: INSERT incident_activity "📚 Knowledge articles retrieved"

    %% === EVIDENCE SCORING ===
    BE->>BE: calculateEvidenceStrength(incidents, articles)
    Note over BE: Backend-computed score 0-100<br/>Never generated by Gemini

    %% === ANOMALY DETECTION ===
    BE->>DB: RPC detect_incident_cluster(category, service, window=60min)
    DB-->>BE: cluster_detected, incident_count
    alt Cluster Detected
        BE->>DB: UPDATE is_anomaly=true, anomaly_type=incident_cluster
        BE->>DB: INSERT incident_activity "🚨 Anomaly detected"
    else No Cluster, Check Novel
        alt max_similarity < 0.60
            BE->>DB: UPDATE is_anomaly=true, anomaly_type=novel_incident
            BE->>DB: INSERT incident_activity "🚨 Anomaly detected"
        end
    end

    %% === AI INVESTIGATION ===
    BE->>Gemini: RAG investigation prompt (incident + evidence + hallucination guard)
    Gemini-->>BE: Structured JSON {causes, actions, escalation, confidence}
    BE->>BE: Zod validate, enrich evidence_used from retrieval
    BE->>DB: UPDATE incidents (ai_analysis, evidence_strength, embedding, analysis_status=completed)
    BE->>DB: INSERT incident_activity "🤖 AI investigation completed"

    alt Escalation Recommended
        BE->>DB: INSERT incident_activity "🚨 Escalation recommended by AI"
    end

    %% === FRONTEND POLLING PICKS UP RESULT ===
    FE->>BE: GET /api/incidents/:id (poll)
    BE-->>FE: Updated incident with full analysis
    FE->>User: Display full investigation, evidence, anomaly alerts

    %% === ENGINEER ACTIONS ===
    Eng->>FE: Review AI investigation
    alt Add Comment
        Eng->>FE: Type comment
        FE->>BE: POST /api/incidents/:id/comments
        BE->>DB: INSERT incident_activity "👨‍💻 Engineer comment added"
    else Escalate
        Eng->>FE: Select team + reason
        FE->>BE: POST /api/incidents/:id/escalate
        BE->>DB: UPDATE status=in_progress, assigned_team
        BE->>DB: INSERT incident_activity "🚨 Incident escalated"
    else Re-analyze
        Eng->>FE: Click Re-analyze
        FE->>BE: POST /api/incidents/:id/analyze
        BE->>DB: UPDATE analysis_status=pending
        BE->>BE: Background: runAnalysisPipeline()
        BE->>DB: INSERT incident_activity "🔄 Re-analysis requested"
    else Resolve
        Eng->>FE: Enter resolution text
        FE->>BE: POST /api/incidents/:id/resolve
        BE->>DB: UPDATE status=resolved, resolution, resolved_at
        BE->>DB: INSERT incident_activity "✅ Incident resolved"
        BE-->>FE: Updated incident
        FE->>Eng: Success notification
    end
```

## Gemini Failure Path

```mermaid
flowchart LR
    A["Incident Created\nSaved to DB ✅"] --> B["AI Pipeline Starts"]
    B --> C{Gemini API Call}
    C -->|Success| D["Update incident\nwith AI data"]
    C -->|Failure| E["analysis_status = failed"]
    E --> F["Activity: ⚠️ AI analysis failed"]
    F --> G["UI shows:\nRetry Analysis button"]
    G --> H{Engineer clicks Retry}
    H --> B
```

## Persistence Guarantee

> **The incident is ALWAYS saved before any AI processing begins.**
> A Gemini failure, timeout, or rate limit will NEVER cause a ticket to be lost.
> Engineers can always retry analysis from the UI.
